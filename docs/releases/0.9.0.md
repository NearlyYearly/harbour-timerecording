Tested: by the author on a Jolla Phone (2026) with Sailfish OS 5.2.0.22, in daily use and with
the test build 0.8.4-1.test1, which has the same app files as this release (only the version
differs). Before the build: pytest, the QML tests and the desktop smoke run. What was used on
the phone and what was not is listed per feature in the README.

## Known quirks
- Reminders only run while the app is open (also on the cover); closing the app stops them.
  Reminders with the app closed need `timed`, whose entries show in the Clock app; not decided
  yet (D-014, Q3).
- Not in the Jolla Store: its validator does not allow the `Notifications` permission the
  reminders use, nor the D-Bus file that lets a notification start the app (D-005).
- Vacation, Flexitime and SPX export now take two steps (month page first), so that no menu
  has more than four items (D-032).
- Undo sits in the day's header and scrolls away with a long list of lines (D-032).
- English only; the translation catalogue is in place for other languages (D-031).

## Changes since 0.8.3
- SPX export: one or several months as a CSV for the ESS Monatsjournal filler, with business
  trips and on-call standby (month page pulley → SPX export).
- *Check in at…* also takes a time later than now; nothing counts until that time.
- Menus with at most four items and no bottom bar. Day pulley: Settings, Day type & note, Add
  line, Check in/out at… (today) or Go to today. Push-up: Week, Month, Templates, Edit several
  days. Month page pulley: Flexitime, Vacation, SPX export.
- Undo above the day's lines, with the name of the step; Redo beside it right after an undo.
- The day type page's pulley opens the day note; accepting it returns to the day.
- Empty task and day type lists say so; Settings and the day note show a scroll indicator; text
  fields show what they are for, and Enter moves to the next field.
- Pressed rows light up both lines; hints that cannot be tapped use the highlight colour.
- Texts are translatable (English for now). Reminders and error messages read as sentences,
  e.g. "The time is in the future."
